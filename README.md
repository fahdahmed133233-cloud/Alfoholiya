# الفحولية | Al Faholya

نسخة تجريبية أولية لتطبيق عربي لتسجيل التمارين والنشاط الشخصي.

## المزايا

- ملف شخصي محلي بالاسم والصورة، دون كلمة مرور.
- واجهة عربية كاملة باتجاه RTL وتصميم متجاوب.
- تمارين جاهزة وإمكانية إضافة تمارين مخصصة.
- تسجيل التكرارات يدويًا أو بالتعرف الصوتي عند دعم المتصفح.
- مؤقّت للتمارين المعتمدة على الوقت.
- سجل الجلسات وإحصائيات النشاط الأسبوعية.
- حفظ البيانات على الجهاز مع تصدير نسخة احتياطية واستعادتها.
- أساسيات PWA عبر Manifest وService Worker.

## التشغيل المحلي

1. افتح مجلد المشروع في VS Code.
2. شغّل Live Server على `index.html`، أو شغّل:

   ```bash
   python -m http.server 8000
   ```

3. افتح `http://localhost:8000`.

## الملفات

- `index.html` — هيكل التطبيق والواجهات.
- `styles.css` — التصميم والحركات والتجاوب.
- `app.js` — منطق التطبيق والتخزين والتمارين.
- `manifest.webmanifest` — تعريف تطبيق الويب القابل للتثبيت.
- `sw.js` — التخزين المؤقت للعمل دون اتصال بعد أول تحميل.
- `icon.svg` — أيقونة التطبيق.

## ملاحظات

- البيانات محفوظة في LocalStorage على نفس المتصفح والجهاز. لا توجد قاعدة بيانات أو مزامنة سحابية في هذا الإصدار.
- التعرف الصوتي يعتمد على دعم المتصفح لـ Web Speech API وإذن الميكروفون، وقد يتطلب HTTPS أو localhost.
- تسجيل الدخول عبر Google غير مفعّل بعد.
- صورة الملف الشخصي لا تُستخدم لتحليل الجسم أو تقييم المظهر.
